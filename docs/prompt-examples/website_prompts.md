# Test Prompts: Websites

Test prompts for evaluating the agent's website generation quality across archetypes, complexity levels, and style expectations. Prompts are designed to exercise the full runtime surface: multi-page navigation, forms with validation, state management, animations, auth, dynamic routes, charts, theming, and responsive layouts.
