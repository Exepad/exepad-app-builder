# Test Prompts: Custom Apps

Test prompts for evaluating the agent's ability to handle hybrid and cross-pattern apps that combine website, form, and data app elements. Custom apps test navigation decisions, backend scoping, and pattern mixing.

---

## Website + Data App (Public Site + Admin Backend)

1. "Create an event management platform — public event listing page, registration form, and an admin dashboard to manage events and attendees"
2. "Build a job board with a public job listings page, application form, and an employer dashboard to manage postings and applicants"
3. "Make a membership organization website — public homepage with mission and programs, member registration, and an admin panel for member management and dues tracking"
4. "Create a conference website with speakers, schedule, ticket purchasing, and an organizer dashboard for managing sessions and registrations"
5. "Build a coworking space platform — public marketing site with plans and amenities, booking form, and an admin panel for space and member management"
